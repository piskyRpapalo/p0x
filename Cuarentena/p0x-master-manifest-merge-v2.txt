2. DOCTRINA ABSOLUTA Y PRINCIPIOS DE p0x
================================================================================

2.1. p0x.core.codice (La Constitución de verify_pow.sh)
El Códice representa la frontera inalterable de soberanía. La máquina es un siervo lógico; el humano es la autoridad absoluta.
- Mandato de Fricción Criptográfica: Ningún diff de configuración, actualización de base de datos o ascenso de misión puede aplicarse automáticamente. El sistema propone un cambio en formato "spec_ready" (ámbar 🟡) y calcula su SHA-256. El operador humano debe verificar el código, firmar el hash con su clave privada Ed25519 offline usando su máquina local, y entregar el archivo .sig de firma detached.
- verify_pow.sh: Script de arranque de sistema. Ejecuta secuencialmente:
  1. Cálculo del checksum de los binarios críticos del sistema y del core de Aurelius.
  2. Comprobación de la firma del manifiesto del nodo (`manifest.json.sig`) contra `sovereign_ed25519.pub`.
  3. Ejecución de un comando de integridad de base de datos SQLite (`PRAGMA integrity_check`).
  4. Si alguna firma no coincide o se detecta corrupción, el script aborta con exit code 1, detiene la interfaz y desconecta las API de red de Hexelion para proteger el metal de manipulaciones ajenas.

2.2. p0x.laboratorio.doctrina (Mandato Operativo del Proyecto Merge)
El Proyecto Merge es el laboratorio epistémico de p0x. Es una base de datos analítica local que devora código externo y, utilizando la arquitectura de datos (para analizar rendimiento térmico y límites físicos de silicio) y la ciencia del lenguaje (para unificar requisitos bajo la sintaxis estricta EARS y eliminar el ruido corporativo de la nube), genera "Meditaciones".
- El flujo es: Ingesta Cruda ➔ Auditoría Crítica de Vulnerabilidades de Red/Memoria ➔ Especificación de Absorción en p0x (Capa Oro) ➔ Creación de la Meditación ➔ Integración en Aurelius para la comunidad.

2.3. p0x.laboratorio.silicio (Sovereign Silicon Code Optimization Protocol)
Protocolo de reescritura de código optimizado para microcontroladores ARM y sistemas aislados:
- Priorizar la compilación estática (vincular dependencias en tiempo de build, desactivando cargadores dinámicos).
- Desactivar recolección de basura o llamadas frecuentes a malloc en caliente. Utilizar buffers estáticos prealocados al inicio del bucle.
- Reducir el tamaño de los modelos y datos mediante cuantización determinista (priorizando IQ-quants si existe matriz de importancia, o K-quants mixtos).
- Mapear bases de datos y archivos pesados en el espacio de memoria virtual con mmap para dejar que el kernel de Linux optimice la memoria RAM bajo demanda física.

3. EL STACK FÍSICO Y PEDAGÓGICO DE p0x
================================================================================

3.1. p0x.core.hexelion (Metal, Radiofrecuencia y FastAPI)
Hexelion es la física del proyecto p0x.
- Adquisición de Señal: Lee el espectro electromagnético de forma local mediante dongles de radio RTL-SDR acoplados a USB. Ejecuta binarios ligeros nativos de C: dump1090 a 1090 MHz para telemetría ADS-B de aviones comerciales; ais-catcher en VHF para señales marítimas de posicionamiento AIS.
- FastAPI Gateway: Servidor web asíncrono en localhost (`127.0.0.1:8000`). Enruta las lecturas crudas del puerto TCP local y los datos del bus de sensores ESP32 (voltaje solar, temperatura de nodo) hacia la base de datos de observaciones SQLite.
- Fusible de Honestidad Física: Ante cualquier fallo físico en el puerto USB o una caída de voltaje de las baterías, el gateway detiene la simulación e informa en pantalla con un monospace rojo parpadeante "NO DATA" indicando el componente exacto y el timestamp, impidiendo falsear lecturas en la base de datos de observaciones.

3.2. p0x.core.le_jardin (Presupuesto Energético de Carbono y Sol)
Le Jardin es el entorno físico de bajo consumo. Dicta las directivas de carbono:
- Monitoreo del voltaje del panel solar y la carga de baterías mediante microcontroladores ESP32 de ultra-bajo consumo.
- Inferencia Solar Degradada: Si Le Jardin reporta voltajes por debajo del umbral óptimo, el gateway FastAPI de Hexelion ordena al Centinela de Hardware reducir el uso de Ollama: limita dinámicamente el número de hilos de CPU en la inferencia (p. ej., reduciendo de 8 a 1 o 2 hilos mediante el flag `-t` de llama.cpp) o descarga el modelo de la VRAM para enfriar el nodo y evitar el OOM Killer.

3.3. p0x.core.sendero (La Ruta de Aurelius M0-M7 en Sintaxis EARS)
La ruta formativa comunitaria se fragmenta en ocho misiones estricta y linealmente bloqueadas bajo compuertas criptográficas:
- Misión M0 (The Totem): Generación de identidad local, derivación de claves Ed25519 desde 12 palabras.
- Misión M1 (The Fire): Carga eficiente e inferencia segura de modelos locales (Qwen) sin conexión.
- Misión M2 (The Water): Indexación y persistencia de memoria epistémica en SQLite.
- Misión M3 (The Wind): Orquestación asíncrona de prompts y logs de interacciones.
- Misión M4 (The Air): Ingesta local de telemetría física de radiofrecuencia (ADS-B / AIS).
- Misión M5 (The Pact): Sincronización descentralizada offline de par a par entre nodos edge.
- Misión M6 (The Stone): Configuración de enlaces virtuales seguros (mTLS, VPN cifrada).
- Misión M7 (The Earth): Compilación mínima y sellado final inmutable de tu nodo.
- Sintaxis EARS: Todos los entregables se validan bajo requisitos formales escritos en:
  `WHEN [condición] IF [precondición] THE [sistema] SHALL [acción]` de betta-tech para descartar alucinaciones de diseño.

4.1. Filosofía de Diseño y Fricción Pedagógica (Portapapeles Soberano)
- El busto de mármol de Aurelius simboliza la ley estoica y el silicio.
- Portapapeles Soberano: Se prohíbe copiar comandos de forma automatizada al sistema del host. La máquina propone el script y el operador humano debe seleccionarlo a mano y realizar la combinación física Ctrl+C. Esto asegura la auditoría de cada línea de código.
- Scaffolding Faded (Retiro de Andamios): Las misiones proveen plantillas guía en `_scaffold/`. Cuando se verifica y firma criptográficamente el éxito de la misión actual, el script verify_pow.sh comprime los andamios en `~/.aurelius-p0x/archive/` en modo de solo lectura y elimina físicamente los archivos del espacio de desarrollo, forzando la autonomía técnica.

4.2. Arquitectura Medallion en Disco (Bronze, Silver, Gold y Escritura Atómica)
- Capa Bronze: Log incremental JSONL inmutable en disco (`data/bronze/`). Almacena interacciones crudas, logs y telemetría de sensores en caliente. Se pausa la escritura automáticamente durante inferencias complejas de Ollama para no asfixiar el bus de E/S.
- Capa Silver: Almacén consolidado mensual en un único archivo de propuestas cursado por línea (`proposals_YYYY-MM.jsonl`). Facilita búsquedas y lecturas por bloques o cursores de 10-20 registros sin abrir múltiples archivos. Es ideal para hardware ARM. El Modo Cosecha (Harvest Mode) procesa estas páginas para aprobación humana.
- Capa Gold: El Ledger de la Verdad Firmada (`gold_chain.jsonl`). Cada bloque de conocimiento está indexado con el hash SHA-256 del bloque anterior. SQLite unificada (`~/.aurelius-p0x/db/aurelius_state.db`) es un derivado de esta cadena.
- Escritura Atómica: Para evitar corrupciones de datos por cortes de corriente física en Le Jardin, el sistema escribe los archivos temporales en `.tmp` y ejecuta un renombrado atómico (`rename`) sobre el disco solo tras verificar el cierre correcto del archivo.

4.3. La Forja (The Forge) y Validación Dual Asíncrona
Es el rito de paso para ascensos formativos o consolidación de tópicos en Gold:
- Dominios Técnicos: El Preceptor local de Qwen te interroga sobre el código. Compara semánticamente tu respuesta con la rúbrica mediante `nomic-embed-text` locales en la base de datos sqlite vector, requiriendo una similitud del coseno >0.75.
- Dominios Blandos: Requiere un ensayo reflexivo de >500 caracteres. Para no agotar CPU ARM ni baterías, se aplica una heurística instantánea O(N) de diversidad léxica:
  `Ratio de Entropía = Palabras Únicas / Palabras Totales`
  Si el ratio es superior a 0.4, se aprueba la competencia. Si repite palabras clave para engañar a la máquina, el ratio decae y se aborta el rito.
- Feedback Visual: Durante el cálculo de la Forja, la pantalla de React muestra el busto de mármol emitiendo un pulso de luz lento en Catppuccin Mocha ("Forjando..."). Al finalizar, destella en cobre para el éxito o se apaga si falló.

4.4. La Mesh Soberana y el Bastión Cobre (Límite Dunbar de 100 mTLS)
Sincronización descentralizada y compartición de recursos:
- Límite Dunbar: El archivo de pares `known_peers.json` tiene un límite físico e inquebrantable de exactamente 100 nodos de confianza.
- Inferencia de Red con Antifaz: Si un nodo de la Mesh te pide ayuda para procesar un prompt, Aurelius solicita tu consentimiento mediante alerta en pantalla. Al aceptar, el hilo de inferencia corre en un contexto efímero de RAM aislado de tu base de datos sqlite vector, de tu diario y de tus datos Gold. El extranjero no puede ver tus observaciones privadas.
- Enlace Seguro mTLS: La API REST y de WebSockets del nodo se amarra obligatoriamente a la interfaz virtual privada cifrada de Tailscale o Yggdrasil, forzando TLS 1.3 con certificados de autenticación mutua (mTLS) validados contra las firmas Ed25519 del Códice local.

4.5. Las 6 Habilidades Paralelas del Preceptor de Borde
Utilidades de bajo nivel integradas en tu base de datos SQLite sin requerir librerías pesadas:
- 1. El Filtro de Comandos (Command Audit): El modelo Qwen audita tu buffer bash en un entorno de prompt aislado y advierte en rojo si hay peligro de scripts destructivos como rm -rf o exfiltración de red.
- 2. El Calculador Determinista: Aurelius nunca calcula matemáticas complejas usando el generador de texto del LLM. Escribirá un script en Python que realiza el cálculo exacto, lo ejecuta en un entorno sandbox seguro de Linux, y reporta el valor real en la interfaz.
- 3. La Biblioteca Soberana: Procesa OCR local de manuales técnicos PDF o capturas usando Pillow, encolando el texto en Silver para vectorizarse con nomic-embed-text en SQLite y quedar disponible para búsquedas FTS5 instantáneas.
- 4. El Centinela de Hardware: Script local en Python que reporta temperatura de CPU y voltajes. Si la temperatura excede 90°C de forma sostenida, frena la inferencia local para salvar el hardware de microcontroladores. Si la RAM libre baja del 5%, desasigna automáticamente el modelo de Ollama.
- 5. La Brújula Estoica: Sella un Propósito maestro en la cadena Gold. Cada mes, compara las conversaciones con tu Propósito original y te enfrenta a tu propia coherencia.
- 6. El Traductor de Babel: RAG multilingüe local que asimila manuales en cualquier idioma y los expone resumidos en español en tu Gold de manera inmediata, explotando las capacidades multilingües de nomic-embed-text.
