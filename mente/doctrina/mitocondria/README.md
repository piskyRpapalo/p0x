# La Mitocondria — dónde vive cada documento

Tres documentos, dos rutas. No es un descuido:

- `mente/doctrina/mitocondria/MITOCONDRIA_ESPECIFICACION.txt` — contratos (servicio,
  veredicto, histéresis, telemetría, consumidor). Contiene los prompts de F0 y F1.
- `mente/doctrina/mitocondria/MITOCONDRIA_PROMPTS_MIGRACION.txt` — los cuatro prompts
  de F3, uno por consumidor, en orden obligatorio. Bloqueados hasta que F2 cierre.
- `mente/misiones/MISION_MITOCONDRIA_P0X.md` — la misión. Vive en `mente/misiones/`
  porque su propio prompt cita esa ruta literalmente; moverla rompería el prompt que
  cada sesión pega verbatim.

Estado de fases: F0 censo → `mente/auditorias/reflejos.md`. F1 en adelante, pendientes.
